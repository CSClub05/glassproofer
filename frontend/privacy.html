How Glass Spawnproofer should handle schematic uploads, local preferences, diagnostics, cookies, and advertising.

Information we process

When you use the tool, you upload a schematic file so the service can generate a modified .litematic file. The file may include block data, region names, metadata, and other schematic information.

Uploaded files

The intended production setup is to process uploaded schematic files temporarily and delete them after the modified file is returned. Do not store user-uploaded schematics longer than necessary unless this policy is updated to explain that storage.

Custom mappings

Custom block-to-glass mappings are stored in your browser using local storage. They are sent to the backend only when you process a schematic. Clearing browser data or using another device may remove those saved preferences.

Logs and diagnostics

The server may process technical information such as request time, file size, error messages, browser type, and IP address for security, debugging, abuse prevention, and reliability. Avoid logging the contents of uploaded schematic files in production.

Advertising and cookies

If Google AdSense is enabled, Google and other advertising partners may use cookies or similar technologies to serve ads, measure ad performance, and help personalize ads where permitted. Users may manage Google advertising settings through Google’s ad settings.
