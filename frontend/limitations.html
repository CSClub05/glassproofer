Glass Spawnproofer
Tool

Read before use

Limitations

Glass Spawnproofer is useful, but it does not replace full in-game testing or Minecraft’s complete spawning logic.

Current format support

The current version is focused on .litematic input and .litematic output. Sponge .schem import is not complete yet.

Potential spawn spaces, not exact simulation

A schematic usually does not contain all the live-world data needed for perfect mob-spawning prediction. The app does not fully account for biome, dimension, light updates, nearby players, mob type, difficulty, server plugins, or modded spawning rules.

Block-shape edge cases

Minecraft has many partial blocks and version-specific behaviors. Stairs, slabs, snow layers, carpets, trapdoors, fences, walls, hoppers, leaves, modded blocks, and unusual block states may need additional handling.

Color mapping is approximate

The app uses default mappings and user overrides to decide glass colors. Some blocks have no obvious correct color, so manual mapping preferences are supported.

Large files

Very large schematics may take longer to process and can require more memory. Production deployments should set upload limits, processing timeouts, and clear error messages.

Glass Spawnproofer is an independent tool and is not an official Minecraft product. It is not approved by or associated with Mojang or Microsoft.
