FAQ

Answers to common questions about supported files, custom mappings, and what the tool can and cannot detect.

Does Glass Spawnproofer guarantee that every marked block can spawn mobs?

No. It marks potential spawning spaces based on schematic block data. Minecraft uses additional world conditions that may not exist inside a schematic file.

Which file formats are supported?

The current implementation supports .litematic input and outputs a modified .litematic. .schem support is planned but not complete in this build.

Will my original schematic be changed?

No. The app downloads a new marked schematic. Your original file remains unchanged on your computer.

Why is a block getting the wrong glass color?

The default mapping may not include that block yet. Add a custom mapping on the tool page to override the color for that exact block ID.

Do custom mappings sync between devices?

No. They are stored in the current browser using local storage. A future version may add import/export for mapping presets.

Can I use this for Bedrock Edition?

The tool is designed around Java-style schematic formats and Java block IDs. Bedrock behavior may differ and is not the primary target for this version.
