How it works

A plain-language overview of how schematic upload, spawn detection, glass mapping, and download work.

What the tool does

Glass Spawnproofer reads a Minecraft schematic, scans for likely hostile-mob spawning surfaces, places stained-glass marker blocks above those spaces, and returns a new .litematic file.

01

Upload a schematic

Choose a .litematic file from your computer. The backend reads the schematic block data and region information.

02

Scan for potential spawn spaces

The scanner checks floor blocks and the air/headroom above them to identify likely spawnable surfaces.

03

Apply glass markers

For each detected space, the app places stained glass above the floor. The glass color is chosen from default or custom mappings.

04

Download the result

The modified schematic downloads as a new .litematic so the original file stays untouched.

Custom color mappings

If a block maps to an unexpected color, add an override on the tool page. For example, minecraft:warped_hyphae can be mapped to minecraft:cyan_stained_glass. Custom mappings are saved in your browser and sent with each upload.

Important note

The app marks potential spawn spaces from schematic data. It does not fully simulate every in-game spawning condition, such as live light levels, biome, dimension, player distance, or server rules.
